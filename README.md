# Historia de la moda

Sitio estático desarrollado con HTML, CSS y JavaScript nativo. No utiliza frameworks ni procesos de compilación.

## Ejecutar localmente

Abrir `index.html` en un navegador o servir la carpeta con cualquier servidor estático.

## Estructura

- `index.html`: estructura y contenido.
- `css/styles.css`: estilos y aviso para pantallas móviles/tablets.
- `js/main.js`: interacciones de navegación y diálogos.

## Nota sobre los recursos visuales

Las dos imágenes de referencia de portada y línea de tiempo están enlazadas temporalmente a las exportaciones de Figma. Antes de publicar el sitio, deben incorporarse como archivos locales en `assets/images/` y actualizar sus rutas en el HTML. Los modales, ampliaciones y pantallas de detalle de cada época todavía requieren trasladar los marcos correspondientes de Figma; esta primera entrega establece la base de navegación y la experiencia de escritorio.
